A one-line safety warning label for humans, written in the flat voice of product safety copy: "WARNING: This human runs on coffee, spite, and the unshakable belief that it read the instructions." The program writes that single line to `entry.txt` in the harness output directory — funny first, plausible second, with the laugh landing in the last few words.

## Run it

```sh
node main.ts
```

The label is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is not set). Node 22, standard library only, no dependencies.
